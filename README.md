# 微博评论爬虫

基于微博移动端 API（m.weibo.cn）的评论数据采集工具。仅支持扫码登录，输出 CSV 格式。

## 功能

- **扫码登录**：自动弹出二维码，登录状态自动缓存
- **抓取主评论**：支持分页抓取所有评论（热门排序）
- **自动重登**：Cookie 失效时自动重新扫码登录并从头抓取
- **子评论抓取**：可选抓取每条评论的回复（支持分页）
- **CSV 输出**：UTF-8 BOM 编码，Excel 可直接打开
- **增量存盘**：每页增量保存，中断不丢数据
- **智能限速**：随机请求延迟 + 指数退避重试
- **友好错误提示**：Cookie 过期、帖子不存在、被拦截等

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行（首次自动扫码登录）

```bash
# 首次运行会弹出二维码，扫码后自动开始抓取
python main.py https://m.weibo.cn/detail/5324881308421206

# 或直接用帖子 ID
python main.py 5324881308421206
```

### 3. 常用命令

```bash
# 抓取全部评论（不限页数）
python main.py 5324881308421206

# 抓取子评论（每条评论的回复）
python main.py 5324881308421206 --sub-comments

# 限制评论条数（如最多 500 条）
python main.py 5324881308421206 --max-count 500

# 限制最大页数
python main.py 5324881308421206 --max-pages 50

# 强制重新扫码登录（忽略缓存）
python main.py 5324881308421206 --login

# 调整请求间隔（降低被封风险）
python main.py 5324881308421206 --delay-min 2 --delay-max 5

# 指定输出目录
python main.py 5324881308421206 -o ./my_output
```

## 命令行参数

### 位置参数

| 参数 | 说明 |
|------|------|
| `target` | 微博帖子 URL 或纯数字 ID（必填） |

### 认证

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--login` | 强制重新扫码登录（忽略已缓存的 Cookie） | `false` |
| `--qr-display` | 二维码显示方式：`auto`（弹窗）/ `window`（GUI）/ `ascii`（终端）/ `url`（仅 URL） | `auto` |

### 输出

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-o`, `--output-dir` | 输出目录 | `output` |

### 抓取控制

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--max-pages` | 最大抓取页数，0=不限制 | `0` |
| `--max-count` | 最大评论条数，0=不限制 | `0` |
| `--sub-comments` | 同时抓取子评论（评论的回复） | `false` |
| `--sub-comment-limit` | 每条评论最多抓取的子评论数 | `30` |

### 速率控制

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--delay-min` | 最小请求间隔（秒） | `1.0` |
| `--delay-max` | 最大请求间隔（秒） | `3.0` |
| `--retry` | 失败重试次数 | `3` |
| `--timeout` | 请求超时（秒） | `15` |

### 其他

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-v`, `--verbose` | 详细日志输出 | `false` |
| `--version` | 显示版本号 | - |
| `-h`, `--help` | 显示帮助信息 | - |

## 运行流程

1. **扫码登录**：首次运行或 Cookie 失效时，自动弹出二维码窗口
2. **确认登录**：用微博 App 扫码并确认登录
3. **获取帖子信息**：校验帖子是否存在
4. **抓取评论**：从第一页开始，自动分页抓取所有评论
5. **可选：抓取子评论**：对每条有回复的评论抓取子评论
6. **保存数据**：输出为 CSV 文件（UTF-8 BOM 编码）

**Cookie 缓存机制**：
- 登录成功后 Cookie 自动保存到 `.weibo_cookie.txt`
- 下次运行自动读取缓存，无需重复扫码
- Cookie 失效时自动弹出二维码重新登录

## 输出文件

保存在 `output/weibo_{帖子ID}_{时间戳}.csv`，UTF-8 BOM 编码，Excel 可直接打开。

### CSV 字段说明

| 字段 | 说明 |
|------|------|
| `comment_id` | 评论唯一 ID |
| `post_id` | 所属帖子 ID |
| `parent_comment_id` | 父评论 ID（子评论使用） |
| `is_sub` | 是否为子评论（0/1） |
| `created_at` | 评论创建时间 |
| `text` | 评论内容（纯文本，已清洗 HTML） |
| `like_count` | 点赞数 |
| `reply_count` | 回复数 |
| `source` | 客户端来源 |
| `user_id` | 评论者用户 ID |
| `user_name` | 评论者昵称 |
| `user_verified` | 是否认证（0/1） |
| `user_profile_url` | 评论者主页 URL |
| `user_avatar_url` | 评论者头像 URL |

**子评论存储**：每条子评论作为独立一行存储，通过 `parent_comment_id` 关联父评论。

## 常见问题

**Q: 提示"Cookie 已过期"？**
A: Cookie 失效时会自动弹出二维码重新登录，无需手动操作。

**Q: 二维码弹窗没显示？**
A: 可使用 `--qr-display ascii` 在终端显示 ASCII 二维码，或使用 `--qr-display url` 打印二维码图片 URL。

**Q: 抓取速度慢？**
A: 可调整 `--delay-min` 和 `--delay-max` 降低间隔，但过快可能导致被封。

**Q: 能抓多少条评论？**
A: 理论上可抓取所有评论，热门排序通常限制在 1000 条左右，按时间排序可获取更多。

**Q: 支持哪些输出格式？**
A: 仅支持 CSV 格式。CSV 采用扁平结构，每条子评论单独一行，便于 Excel 筛选和分析。
